# Data Handling for a Public Portfolio

This repository is public. Before adding media or records, verify that you have permission to share them publicly and that sharing follows generator, dataset, and source terms.

- Do not publish private, identifying, confidential, or sensitive inputs, outputs, transcripts, or notes.
- Prefer links to permitted source material over copying media into the repository.
- Record tool/model name, version, date, and source/license/terms in the asset manifest.
- Do not expose credentials, API keys, private URLs, or personal contact details.
- Keep raw notes factual and respectful; remove unrelated personal information.
- If a source cannot be shared, do not add it to this public repository.
- Confirm that screenshots, audio, video, and images are yours to share before uploading.
