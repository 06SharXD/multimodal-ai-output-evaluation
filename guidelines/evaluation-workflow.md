# Evaluation Workflow

## Before generating or collecting outputs
1. Choose a prompt and assign a unique prompt ID.
2. Use only tools and materials you are permitted to use. Record tool/model/version and relevant settings.
3. Assign each output a unique output ID; record provenance in the asset manifest.
4. Keep prompt text, generation settings, and output identity linked. Avoid private or identifying source material.

## Before each rating session
1. Check that you can give the task focused attention and the environment is suitable.
2. For audio, choose a quiet place and a comfortable, consistent listening volume.
3. Record date, session number, time spent, and relevant conditions in the evaluation log.
4. Read the prompt before opening the output.

## For each output
1. Identify the prompt's requested content and constraints.
2. Apply the matching modality rubric. Score prompt adherence separately from quality.
3. Enter one row per criterion in the rating template.
4. Record an evidence location and concise observation for any issue or judgment. Separate observation from rationale.
5. Mark uncertainty where the evidence does not support a confident judgment.
6. For comparisons, rate each output independently first. State the comparison basis and evidence; preference is optional and owner-authored.

## After a session
- Review entries for missing IDs and unsupported claims, not to force agreement.
- Record interruptions and any re-review.
- Take a 30-minute break between extended blocks. If the process changed, document the change.
- Keep original records; make corrections traceable.

## Suggested phases
Setup; prompt practice; rubric familiarization; calibration; owner-led human evaluation; analysis and reporting; portfolio summary. The owner performs every media review and rating.
